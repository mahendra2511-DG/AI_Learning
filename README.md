# 90 Days to Become an AI Engineer
Developed and updated by **Mahendra Singh**.

One file: `index.html`. No server, no API key, no build step.

## Deploy
Upload this folder to Vercel, Netlify or GitHub Pages (or just open `index.html`).

## How students use it
1. Enter name + start date and lock it. Weeks, ship dates and the 92-day tracker count from that date.
2. Progress is saved in their own browser. "Progress code" moves it to another device.
3. **Ask AI tutor** (bottom-right): the student types a doubt and the site opens it in **their own Claude**
   (claude.ai, they sign in with their own account, free plan works) with their current week and project
   already filled in. A ChatGPT button and "Copy question" are there too.
   - Optional: a student who has their own Anthropic API key can save it in the tutor panel to chat inside the site.
     The key stays in that student's browser and goes only to Anthropic.

The site owner never needs or stores any API key.

Roadmap content based on "90 Days to Become an AI Engineer: The Oct → Dec Roadmap" by Sakshi Jaiswal (AI in Plain English).
