Before you start

Can this really be done in 90 days?

Yes, if you already write basic code in any language: loops, functions, a little Git. New to coding? Keep the plan but slow it down: take Week 0 seriously, add a month of Python, then follow the same order.

"AI engineer" here means someone who builds dependable products on top of existing models: chatbots that stay grounded, agents that finish the job, search that understands meaning. It is not ML research, and you won't be designing new architectures.

The only daily rule

The 1 · 1 · 1 method

1 hr

Learn

One video, one doc page or one chapter. Not five tabs. Take notes by hand.

1 hr

Build

A tutorial only counts once you've committed code after it.

1 post

Share

Every Friday, post what you shipped: a screenshot, a lesson, a failure. Recruiters look for builders, not certificates.

Roughly 2 hours on weekdays and 4 on weekends. Consistency beats intensity.

Stay on the road

What to learn, what to skip

Learn now

  • Calling LLM APIs well
  • Embeddings & retrieval
  • Tool use & agent loops
  • Writing evals
  • Deploying & monitoring
  • Reading model docs fast

Skip for now

  • Deep backprop math: useful later, not needed to ship products now.
  • Training models from scratch: that's research; you're doing engineering.
  • Every new framework: learn the concepts, frameworks are syntax.
  • Comparing 10 vector DBs: pick one and move on.
  • Collecting certificates: one deployed app beats ten badges.
  • Waiting to feel "ready": you won't. Start anyway.
